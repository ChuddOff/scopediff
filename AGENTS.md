# ScopeDiff — инструкции для coding-агентов

Русскоязычный мобильный AI-first помощник фрилансера. Слоган: «От переписки к договорённостям». Цель — рабочий MVP за 8 часов, без необоснованного усложнения. Официальный продуктовый трек LeCodes: полноценный самостоятельный сценарий, публикация LeStore, видео, реальный телефон. Не добавлять неработающие кнопки.

## Владение кодом
- `mobile/`: LeCodes SDK + TypeScript, собственный runtime, не React Native/React/DOM/npm в клиентском коде. Разработчик мобильного приложения.
- `backend/`: Андрей, FastAPI + PostgreSQL + DeepSeek API, PDF, одна HTML-страница заказчика без регистрации.
- `shared/types.ts` и `shared/api.md`: единый контракт. Backend Pydantic/OpenAPI должен соответствовать ему. В mobile при необходимости скопировать типы в папку проекта (без runtime npm import), не менять поля односторонне.
- `.env` не коммитить; AI-ключ только на backend.

## UX
Две вкладки: Заказы и Услуги. На обеих `scope.diff` по центру без иконки. Светлый фон #F5F6F8, карточки #FFFFFF, текст #111827, акцент #635BFF, AI-блок #EEEDFF, успех #16A34A, замечания #D97706, скругления 12–16. Без финансовой статистики, цен в списках, тематических иконок услуг, CRM, отдельного поля заказчика. Карточка услуги: название + до 3 строк описания. В списке услуг яркий блок «Импорт услуг с AI», внизу «Создать услугу»; оба ведут на выбор голос/скриншоты/вручную. Услуга — название и подробное описание для AI (состав работ, ограничения, раунды правок). AI может массово импортировать услуги, сразу сохраняя их. Заказы — активные/завершённые, последние обновлённые первыми, счётчик активных, карточка: название, услуга, статус. Новый заказ — те же три способа ввода. Услуга необязательна, при создании из услуги предвыбрана. AI сразу сохраняет заказ и открывает готовую карточку; если были правки, сразу создаёт черновик предложения. Не заставлять проходить промежуточную форму проверки. Ручной ввод открывает компактную форму. Карточка заказа: название, услуга, статус, «О заказе» (согласованное и выполненное кратко, с возможностью редактирования), срок если есть, правки, главное действие «Добавить правки». Не показывать технические поля как форму по умолчанию. Открытое предложение — добавить замечания/открыть его, не создать второе параллельное. Предложение показывать как документ; карандаш открывает редактор. Цена только в предложении, null не равен 0. Поделиться: PDF/Markdown/текст/интерактивная ссылка (если реализована). Версии сохраняются. Согласование вручную или через ссылку, без обязательного участия второй стороны.

## Приоритеты
1. Сессия, CRUD, текстовый AI, готовое предложение, редактирование, текстовый экспорт.
2. Реальные скриншоты и голос, PDF, история версий и согласование.
3. Интерактивная ссылка (не блокирует основной сценарий), полировка, публикация.
Сначала мок-данные фронтенда с теми же типами, затем настоящий API. Тестировать ошибки, перезапуск, доступ к чужому ID, актуальность версии, отсутствие неизвестной цены. Не имитировать успешный AI на проде. Проверить кириллицу PDF и share на телефоне. Не оставлять секреты и личные данные в логах.
